One of the simpler games I made, but it still involves some (*virtual*) physics.

## Basics

Left arrow moves the left paddle.

Right arrow moves the right paddle.

Space/Up to shoot the spring.

## Pushing

Update: Use A/S/D to push the pinball table itself (as much as you want) - only here can you do this without **TILT**ing!

## Scoring

Collect yellow coins for 10 points, and blue coins for 50 points!

## Powerups

x2: Double the points you get for a while!<BR>
Shield: Stop the ball from falling into the "edge tunnels" for a while!<BR>
Heart: +1 life<BR>
Enlarge: Increases the size of the coins and powerups for a while!

#### Updates
After some play-testing, I made the gap between Flippers bigger - personally, it was a bit too easy just by spamming the paddles to keep the ball in check.
